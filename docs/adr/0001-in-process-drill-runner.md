# 进程内推演运行器与每步持久化

单机单事件焦点的产品形态下，推演的自动推进（模拟时钟、场景演变、Agent 步骤、关键节点暂停）由服务端进程内的唯一运行器驱动。每推进一步即写入 SQLite（含图状态），进程重启后从落库状态恢复；前端仅轮询读取状态，无推送基础设施。

## Considered Options

- **前端轮询触发"推一步"**：推进权威交给前端，多标签页会重复推进同一演练，弃用。
- **独立常驻进程 / 消息队列**：单机单用户场景下增加部署与运维复杂度，无对应收益，且技术栈固定不包含，弃用。

## Consequences

- 数据库是推演进度的唯一事实来源，运行器只是"当前这步的执行者"，随时可被重建。
- dev 服务器重启会中断运行器，但演练可从落库状态恢复；恢复语义在第 2 步实现时定义。

# 02: 指挥调度智能体与定级确认点

**What to build:** 推演推进到研判阶段：指挥调度智能体基于事件证据提出建议等级与理由，推演自动暂停（演练进入 awaiting_confirmation，模拟时钟同步停走），CLI 交互式展示建议与理由，操作员确认或调整等级后推演继续；时间线记录 ⚑ 定级节点与确认耗时。提供 `--auto` 全自动模式跳过确认（对应场景配置的确认开关）。规格见 `../spec.md`。

**Blocked by:** 01（运行器骨架 + 感知上报）

**Status:** ready-for-agent

- [ ] 事件上报后，调度智能体输出结构化的建议等级（Ⅰ–Ⅳ）与理由，经 zod 校验
- [ ] 进入定级节点时演练状态转为 awaiting_confirmation 且模拟时钟停走；确认后恢复 running
- [ ] CLI 展示建议等级、理由，支持确认或输入调整等级两种操作
- [ ] 时间线 grading 节点 requires_confirmation=1，detail 记录确认耗时与操作员动作（operator_action 节点）
- [ ] `--auto` 模式自动采纳建议，不暂停
- [ ] 调度智能体坏输出/超时 → 重试一次 → 规则默认定级 + anomaly 节点，推演不中断（缝 2 测试）
- [ ] 缝 1 测试：人工确认路径与 auto 路径均断言事件定级结果、⚑ 节点与状态机流转

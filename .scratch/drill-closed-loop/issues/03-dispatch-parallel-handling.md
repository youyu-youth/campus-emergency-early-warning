# 03: 任务方案确认、三角色并行处置与重新调度

**What to build:** 定级确认后，调度智能体产出任务方案（保安/医务/后勤的角色、标题、说明），经确认点（可就地增删改派）后派发；三类任务并行执行，耗时、资源消耗、成败由规则 + 种子计算，执行叙述由模型生成；任务反馈写入时间线，事件推进到已控制。场景演变里程碑写入时间线，并可触发调度智能体的重新调度评估，经同一确认缝加派或调整任务。规格见 `../spec.md`。

**Blocked by:** 02（定级确认点）

**Status:** ready-for-agent

- [ ] 任务方案在确认点展示并可调整（改角色、改内容、增删任务）后执行
- [ ] 确认后任务逐条落库并进入执行，三角色在图中并行推进、各自汇合反馈
- [ ] 每个任务的耗时、资源消耗、结果（done/failed）由规则 + 种子确定性计算；失败任务可重试
- [ ] feedback 时间线节点记录执行叙述、耗时与资源；事件状态推进到 handling → controlled
- [ ] 演变里程碑到期写入 status_change 节点（规则驱动，非模型生成）
- [ ] 里程碑触发重新调度评估：需要时经确认缝加派/调整任务；不需要时记录评估结论
- [ ] 处置智能体坏输出/超时降级：规则默认反馈 + anomaly 节点，不阻塞其他角色（缝 2 测试）
- [ ] 缝 1 测试：确认、调整改派、并行汇合、失败重试、重新调度路径的断言

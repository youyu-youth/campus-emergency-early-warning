# 04: 通知发布确认与模拟送达

**What to build:** 处置阶段中，通知发布智能体为事件生成面向师生与家长两个受众的通知草稿（内容带显著「模拟演练」标识），经第三个确认点后发布（模拟），送达统计由规则 + 种子计算写入 delivery；分发失败仅标记通知自身为失败，不影响主线推演。规格见 `../spec.md`。

**Blocked by:** 03（任务派发与并行处置）

**Status:** ready-for-agent

- [ ] 每个事件生成 staff_students 与 parents 两个受众的通知草稿，内容含「模拟演练」标识文案
- [ ] 通知确认点暂停推演，CLI 展示通知全文，确认后状态 draft → pending_confirmation → published_sim
- [ ] 送达统计（人数、送达、失败）由规则按种子确定性计算，写入 delivery 字段
- [ ] notification 时间线节点 ⚑ 标记，记录发布时刻与统计
- [ ] 模拟分发失败 → 通知置 failed（可重试），主线推演与处置不受影响
- [ ] `--auto` 模式下通知自动确认发布
- [ ] 通知智能体坏输出/超时降级：规则默认文案 + anomaly 节点（缝 2 测试）
- [ ] 缝 1 测试：草稿生成、确认发布、送达统计、失败不影响主线的断言

# 06: 推演控制与恢复（暂停/恢复/调速/终止/重启恢复）

**What to build:** 操作员可对运行中的演练执行暂停、恢复、调速与终止（终止需二次确认），CLI 提供对应交互；运行器保证同一时间至多一场运行中演练；进程意外重启后，原 running 演练恢复为 paused 态，由操作员手动恢复，模拟时钟从落库状态续算，不丢失进度。规格见 `../spec.md`、docs/adr/0001。

**Blocked by:** 01（运行器骨架）

**Status:** ready-for-agent

- [ ] 暂停/恢复：演练状态与模拟时钟正确流转（running ↔ paused），时间线不丢节点
- [ ] 调速：运行中变速即时生效，已累计模拟时间不受影响（复用时钟纯函数）
- [ ] 终止：二次确认后演练进入 aborted 终态，落库完整保留
- [ ] 发起第二场演练时，若已有 running 演练则拒绝并提示
- [ ] 重启恢复：进程重启后原 running 演练恢复为 paused，操作员手动恢复后时钟从落库状态续算
- [ ] 缝 1 测试：暂停/恢复/调速/终止的状态机断言与重启恢复断言（时钟注入真实时刻，测试保持确定性）
